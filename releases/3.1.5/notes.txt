xewe-os-tools 3.1.5

xewe-os-tools is the Python package behind every XeWe OS firmware project (`xewe`: setup, build,
flash, serial, provision, test, release, release-card, format, brand-lint) and the reusable GitHub
workflows the other repos call. 3.1.5 follows 3.1.4 and gives the project's Config.h catalogue its
final form: framed blocks with start and end lines for every block and every section.

CHANGED SINCE 3.1.4

- `xewe modules generate` writes each block of the project's Config.h between
  `/* ---- start <slug> ---- */` and `/* ---- end <slug> ---- */`, each of those lines framed above
  and below by a `/****/` bar of the same length. The block header sentence is gone.
- Inside a block the two sections, `default runtime values` and `compile time defined constants`,
  each have a start and an end line, with a blank line after the start and before the end; an
  empty section is its start line, a blank line and its end line. Entries are separated by one
  blank line; text is in `/* */`, commented-out definitions in `//`.
- Sources are read in three forms: the start and end markers, one marker per section, and the
  `//` markers of modules 3.1.0 (runtime defaults and first-boot values both become default
  runtime values, compile-time constants become compile time defined constants).
- A block is recognised by any of `/* ---- start <slug> ---- */`,
  `/* ---- <slug> (xewe modules generate) ---- */` and `// ---- <slug> (xewe modules generate) ----`,
  so a project with an older block never gets a duplicate, and no block is rewritten.
- Blocks are appended after exactly one blank line, the core first.
- doc/spec.md section 10 and the modules README describe the form.

BREAKING

- None. A project that wants the new form deletes its old blocks from Config.h and runs
  `xewe modules generate` again.

INSTALL

- Projects: `[tools] ref = "3.1.5"` in xewe.toml, then `./setup.sh`.
- Workflow callers: `uses: xewe-labs/xewe-os-tools/.github/workflows/<workflow>.yml@3.1.5`.

TESTING

What was tested, on which tree and with which result: release_card.md, generated by
scripts/release.sh --prepare 3.1.5 and attached to this release.
