xewe-os-tools 3.1.2

xewe-os-tools is the Python package behind every XeWe OS firmware project (`xewe`: setup, build,
flash, serial, provision, test, release, release-card, format, brand-lint) and the reusable GitHub
workflows the other repos call. 3.1.2 follows 3.1.1 and fixes the release card check of the core
workflow. The package itself is unchanged.

CHANGED SINCE 3.1.1

- xewe-core-tests.yml: the release card check runs `xewe release-card verify --ci --unit-only`
  without `--meta-dir`. The core workflow builds no firmware image, so there is nothing to compare
  the card's image rows with, and the empty directory the host job created never arrived in the
  card job (an artifact keeps no empty directory), which failed the check with "not a directory".

BREAKING

- None.

INSTALL

- Projects: `[tools] ref = "3.1.2"` in xewe.toml, then `./setup.sh`.
- Workflow callers: `uses: xewe-labs/xewe-os-tools/.github/workflows/<workflow>.yml@3.1.2`.

TESTING

What was tested, on which tree and with which result: release_card.md, generated by
scripts/release.sh --prepare 3.1.2 and attached to this release.
